1. INTRODUCTION                                    *anvim-introduction*

anvim is a TUI dashboard for Android and Flutter development inside Neovim.
It provides an interactive keyboard-driven interface for running tasks,
viewing logcat, and managing devices — eliminating the need for Android Studio.
Version 1.3.0.

Features:
  - Project auto-detection (Flutter vs Android/Gradle vs Node/npm, git-root aware)
  - System health check (versions + minimums, selectable UI, auto-download)
  - Tool auto-download (sha256 best-effort, no-sudo ~/.local/bin)
  - Task runner (build, clean, run, test, custom, rerun, split + quickfix)
  - Logcat viewer with live filtering (*:LEVEL)
  - Device management (multi-device -s, ANDROID_SERIAL for Gradle, persistent)
  - Emulator/Scrcpy sections auto-hide without adb devices
  - Scrcpy mirror + record (replaces emulator section when installed)
  - Emulator manager (list AVD, launch cold/quick/wipe, kill, boot wait)
  - Theming via highlight groups, LSP diagnostics in dashboard
  - Emulator manager (list AVD, launch cold/quick/wipe, kill, boot wait)

2. INSTALLATION                                    *anvim-installation*

Using lazy.nvim:
>lua
  {
    "your-username/anvim",
    opts = {},
  }
<

Using packer.nvim:
>lua
  use {
    "your-username/anvim",
    config = function() require("anvim").setup({}) end,
  }
<

Downloaded tools live in ~/.anvim/tools/<name>/,
binaries are copied to ~/.local/bin/ (no sudo).

3. COMMANDS                                        *anvim-commands*

  :Anvim           Open the anvim dashboard
  :AnvimCheck      Run system health check
  :AnvimLogcat     Open logcat viewer
  :AnvimRun        Run app directly
  :AnvimTest       Run project tests
  :AnvimRerun      Rerun last task
  :AnvimCustom     Run custom task (picker)
  :AnvimDoctor     Environment doctor
  :AnvimLogcatSave [path]  Save logcat history
  :AnvimHelp       Open this help
  :AnvimEmulator   Launch Android emulator (picker)
  :AnvimEmulatorKill Kill running emulator
  :AnvimScrcpy     Mirror picker (record/stop)
  :AnvimScrcpyKill Stop running mirror

4. KEYMAPS                                          *anvim-keymaps*

Default:
  <leader>ad       Open dashboard
  <leader>al       Open logcat

Dashboard navigation:
  j / k            Navigate up/down (skips headers)
  Enter            Select item
  q / Esc          Close dashboard
  R                Rerun last task
  e                Launch emulator
  m                Scrcpy mirror
  t                Run tests
  x                Cancel running task
  c                Run health check
  r                Run app
  l                Open logcat

Logcat viewer:
  V / D / I / W / E / F   Filter by log level
  T                       Filter by tag (empty = reset)
  S                       Save history to file
  yy                      Copy current line
  /                       Search within logs
  q / Esc                 Close (back to code)

5. CONFIGURATION                                  *anvim-configuration*

>lua
  require("anvim").setup({
    dashboard = {
      width = 0.8,
      height = 0.8,
      border = "rounded",
    },
    health_check = {
      auto = true,
      tools = { "adb", "java", "git", "flutter", "gradle" },
    },
    logcat = {
      max_lines = 5000,
      filter_default = "I",
      no_dashboard_on_close = true,
    },
    tasks = {
      timeout_ms = 300000,
      custom = {
        { label = "Lint", cmd = { "flutter", "analyze" } },
      },
    },
    emulator = {
      boot_timeout_ms = 120000,
    },
    detect = {
      extra_dirs = { "~/tools" },
      max_depth = 3,
      cache_ttl = 300,
    },
    scrcpy = {
      replace_emulator = true,
      max_size = 1920,
      bit_rate = "8M",
      audio = false,
      stay_awake = true,
      turn_screen_off = true,
      record_dir = "~/Videos",
    },
  })
<

Set vim.g.anvim_no_default_keymaps = true to skip default keymaps.

6. HEALTH CHECK                                      *anvim-health*

anvim checks for these tools on startup:
  - ADB          Android Debug Bridge
  - Java         Java runtime (Gradle builds)
  - Flutter      Flutter SDK (Flutter projects)
  - Git          Version control
  - Gradle       Build tool Android

Missing tools show a clear message with install instructions.
Use :AnvimCheck anytime to re-run the health check.
